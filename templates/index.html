WiFi (supported — how the ESP32 actually connects):
  1. Flash your ESP32 with the push-mode firmware, filling in your WiFi name/password.
  2. Set API_KEY in the firmware to match this server's INGEST_API_KEY.
  3. Set SERVER_URL in the firmware to https://YOUR-APP.onrender.com/api/ingest.
  4. Power on the ESP32. Open its Serial Monitor to confirm you see POST -> 200 lines.
  5. Back here, select ESP32 above and click CONNECT.
USB is not supported on this deployed link. A USB cable connects to your own computer, not to this cloud server — there's no physical port here for it to read. USB only works if you run this app locally on the same machine the cable is plugged into.
